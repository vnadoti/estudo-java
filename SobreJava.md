## Visão Geral
Java é uma linguagem de alto nível, tipada estaticamente, orientada a objetos e multiplataforma.

Projetada para ser simples, segura e Confíavel.

## JDK - JRE - JVM
- JDK:
  - Kit completo para desenvolvimento Java (Compilador, Ferramentas).
- JRE:
  - Fornece o ambiente para executar aplicações (Bibliotecas + JVM).
- JVM:
  - Máquina virtual que executa o Bytecode e o converte para a linguagem da máquina.

### Compilação
O Código Java passa por um processo de compilação antes de ser executado.

.Java (Código fonte - arquivo.java) -> Javac -> .class (bytecode) -> Executa na JVM.


## Características do JAVA
- **Portabilidade**: Executa em qualquer sistema operacional.
- **Segurança**: Ambiente confiável e sandbox.
- **Gerenciamento automático de Memória**: Coletor de Lixo (Garbage Collector).
- **Suporte a concorrência**: Multithreading.
